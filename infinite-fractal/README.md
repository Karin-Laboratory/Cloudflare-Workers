# 無限フラクタル探検

https://karin-infinite-fractal.karin-laboratory.workers.dev

独立したブラウザ内マンデルブロ集合ビューア。依存ライブラリ・APIキー・外部API・画像アップロードなし。

ピンチ、スワイプ、ドラッグ、ホイール、ダブルクリック、キーボード操作に対応。4色、リセット、3つの探索地点を搭載。Web Workerで計算し、操作中は低解像度・160反復、停止後は最大85万画素・2400反復で再描画。古い計算を中断し、計算待ちは直前の画像を変形して表示。

「無限」は作品名です。倍精度浮動小数点の制約から約1兆倍で拡大を制限します。有限反復による近似表示です。

index.html が編集元。worker.mjs はHTMLを文字列として内包した配信用Workerです。変更時は同じ内容に再生成してください。wrangler.jsonc はこのフォルダ専用。デプロイはこのフォルダで npx wrangler deploy。既存アプリの設定は変更しません。
